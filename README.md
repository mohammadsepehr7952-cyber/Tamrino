# Tamrino — راه‌اندازی

## ۱) ساخت جدول‌ها تو Supabase
1. برو تو داشبورد پروژه‌ت (Barbod_gym) → **SQL Editor** → **New query**
2. کل محتوای فایل `supabase-schema.sql` رو کپی/پیست کن و **Run** بزن
3. تایید کن که دو جدول `workouts` و `exercises` تو بخش **Table Editor** ساخته شدن

## ۲) فعال کردن ثبت‌نام با ایمیل
تو Supabase Dashboard → **Authentication → Providers** → مطمئن شو **Email** فعاله.
(اگه نمی‌خوای تاییدیه‌ی ایمیل بفرسته، تو **Authentication → Settings** گزینه‌ی "Confirm email" رو خاموش کن تا بعد از ثبت‌نام مستقیم وارد بشی.)

## ۳) اجرا روی سیستم خودت (تست محلی)
چون فایل‌ها ماژول جاوااسکریپت هستن، باید از یه سرور محلی سرو بشن (باز کردن مستقیم فایل با دبل‌کلیک کار نمی‌کنه). ساده‌ترین راه:
- اگه Python نصبه: تو پوشه‌ی پروژه دستور `python -m http.server 8000` رو بزن و برو به `http://localhost:8000`
- یا با VS Code، اکستنشن **Live Server** رو نصب کن و رو `index.html` کلیک راست بزن → Open with Live Server

## ۴) دیپلوی رایگان (تا از هر جا در دسترس باشه)
ساده‌ترین گزینه **Vercel** یا **Netlify** هست:
1. یه ریپو تو گیت‌هاب بساز و این سه فایل (`index.html`, `style.css`, `app.js`) رو داخلش بذار
2. تو vercel.com یا netlify.com با گیت‌هابت وارد شو → New Project → ریپو رو انتخاب کن → Deploy
(چون سایت استاتیکه، نیازی به تنظیم build command خاصی نیست)

## چیزی که الان کار می‌کنه (نسخه‌ی اول)
- ثبت‌نام / ورود با ایمیل و رمز
- اگه برای امروز برنامه‌ای ثبت نشده، فرم ساخت برنامه (عنوان، سطح، مدت، حرکات) رو نشون می‌ده
- کارت تمرین امروز با رینگ درصد پیشرفت
- دکمه‌ی شروع تمرین → تایمر از پایین صفحه شمارش معکوس... در واقع شمارش رو به جلو نشون می‌ده
- تیک زدن هر حرکت → آپدیت آنی درصد رینگ
- سه رینگ آماری (ضربان، دقیقه فعال، کالری) — فعلاً با ضربه‌زدن روش‌ها مقدار رو دستی وارد می‌کنی

## چیزهایی که هنوز نساختیم (قدم بعدی)
- صفحه‌ی تاریخچه/ماه‌های قبل (داده‌هاش تو دیتابیس ذخیره میشه، فقط صفحه‌ی نمایششو هنوز نساختیم)
- ویرایش برنامه‌ی یه روز بعد از ثبت
- اتصال به Apple Health / Google Fit برای پر شدن خودکار ضربان و کالری
